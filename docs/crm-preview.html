O que rola por baixo

1
Scraping do DOM: captura nome, headline, foto, URL, location e empresa atual.
2
POST autenticado: manda payload + token (gerado na primeira config) pra /api/extension/save.
3
Dedupe + criação: backend checa se LinkedIn URL já existe. Se sim, atualiza; se não, cria Person + tenta detectar/criar Company.
4
Toast + link: retorna sucesso, extensão mostra "Salvo" + atalho pra abrir o lead detail no CRM.
5
Bonus right-click: menu rápido pra logar interação (LinkedIn message, engagement) sem abrir o CRM.
Distribuição: primeiro sideload (você baixa o .crx e arrasta no chrome://extensions), depois publicação na Chrome Web Store (US$ 5 fee + 1-3 dias de review).

Auth flow (uma vez só)

1. Você instala extensão
Click no ícone → popup "Conectar conta Boldfy" → abre nova aba do CRM
2. Gera token
Na página /internal/crm/extension-auth, click "Gerar token" → mostra string única "boldfy_ext_xxx"
3. Cola no popup
Cola o token no popup da extensão → todos os saves futuros usam essa auth
